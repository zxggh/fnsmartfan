STC 智能风扇控制器 — 项目总结

    项目概况

      项目    内容
      ──────  ────────────────────────────────────────────────────────────────────────
      位置    /vol1/@appdata/trim.hermes/workspace/fan-controller/
      架构    NAS 做大脑（读温度→算转速→下发），STC 单片机只做 PWM 驱动 + 环境温度上报
      Web UI  http://192.168.1.200:8780（FastAPI + 纯 HTML/JS）
      硬件    STC USB CDC 设备（/dev/ttyACM0，115200），单风扇

    通信协议（精简版）

      命令        说明
      ──────────  ────────────────────────────────────────────────
      GETNTC?     查询环境温度 → NTC: 26.8°C
      F1CPD?      查询风扇转速 → F1_CPD=80%
      F1CPD=80    设置转速（等确认后才更新显示，2s 超时重发 3 次）
      LED=ON/OFF  LED 开关（等 OK 响应才变色）

    核心功能

    • 自动温控：每 3 秒心跳保活（满足固件 5 秒窗口）+ 每 10 秒采集温度（CPU/SSD/HDD 取最高）→ 线性映射 →
    转速变化才下发 F1CPD
    • 温度采集：sensors（CPU）、hwmon_nvme（SSD）、smartctl（HDD，需 disk 组）
    • Web UI：温度仪表盘 + 曲线图、风扇进度条、温控配置（启动/最高温度，可持久化+恢复默认）、LED
    开关、原始命令、调试日志、断连记录（JSON 持久化，掉电不丢失）
    • 断连自愈：连续 3 次心跳失败才判定断连 → 保持连接多次 ping → 端口逐个测试重连（最长 10 分钟）

    文件结构

      fan-controller/
      ├── main.py              # FastAPI 入口：REST API + 心跳 + 自动控温任务
      ├── serial_ctrl.py       # 串口协议层 v3（缓存、确认机制、重连）
      ├── temp_collector.py    # 温度采集（sensors/smartctl/hwmon）
      ├── control.py           # 温控逻辑 + 配置持久化(config.json)
      ├── disconnect_log.py    # 断连记录（disconnect_log.json）
      ├── static/              # Web UI (index.html/style.css/app.js)
      ├── config.yaml          # 串口/服务配置
      ├── start.sh             # 启动脚本（sg dialout+disk 提权）
      ├── install-service.sh   # systemd 服务安装（开机自启）
      ├── install-autostart.sh # crontab @reboot 开机自启
      ├── deploy.sh            # 部署到其他 fnOS
      └── stc-fan-install.sh   # 一键自包含安装脚本

    运维要点

    • 启动：start.sh（已配置 crontab @reboot 开机自启）
    • 重启：pkill -f "uvicorn main:app" 后 bash start.sh
    • 串口权限：dialout 组（控制器）+ disk 组（HDD 温度），sg 双组提权
    • 部署到其他 fnOS：stc-fan-install.sh 一键脚本（自包含）

    关键经验（踩坑记录）

    1. 固件 5 秒心跳机制：控制器 5 秒无命令自动复位 → NAS 心跳必须 <5 秒，且 Web UI 轮询 API 不能抢串口（NTC
    已改缓存，27ms 秒回）
    2. DTR 控制：该设备不支持（Protocol error），无法用 DTR 激活
    3. 设备偶发假死：USB 枚举正常但固件不响应，需物理插拔恢复（宿主机无 root 权限无法软件重置）
    4. 组合命令：F1CPD=x;F2CPD=x 不可靠 → 改单命令分开发送
    5. 锁竞争：串口单锁，API 高频访问会饿死心跳 → 所有查询 API 走缓存，串口只留给心跳和温控

    遗留问题

    • 设备偶发假死（固件侧问题）：建议在固件加硬件看门狗（独立定时器），NAS 端已做检测+日志+断连记录
    • 当前设备间歇性断连现象仍需持续观察验证（已加"命令间隔>5s"诊断日志，下次断连可精确定位）
